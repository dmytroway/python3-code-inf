## Ініціалізація змінних

Для написання змінної в коді потрібно пройти два етапи:

> [!light-yellow] Оголошення змінної
> Потрібно вказати ім'я змінної та тип даних який в ній зберігається.

> [!light-green] Присвоєння значення
> Потрібно за допомогою оператора `=` вказати який об'єкт в пам'яті буде прив'язано до оголошеної змінної.

Разом цих два етапи називають *ініціалізацією змінної*.

В python ми будемо користуватись наступним алгоритмом ініціалізації змінних:

> [!light-purple] Алгоритм ініціалізації змінних
> 1. Вказати ім'я змінної дотримуючись [[snake_case|snake_case]]
> 2. Одразу після назви без пробілів ставимо `:`
> 3. Ставимо пробіл та вказуємо тип даних який буде прив'язано до цієї змінної
> 4. Ставимо знак присвоєння `=` при цьому перед ним та після нього ставимо пробіли
> 5. Вказуємо об'єкт який потрібно прив'язати до оголошеної змінної
   
Приклад коду:

``` python
my_name: str = "Дмитро"
my_age: int = 23
```

## Функція print()

> [!term] Функція (Function)
> Це іменований блок коду, який виконує конкретну задачу. Ми створюємо (оголошуємо) функцію **один раз**, а використовувати (викликати) можемо **скільки завгодно разів**.

В мовах програмування є стандартні функції які достатньо лише викликати щоб отримати результат. Для того щоб вивести дані в консоль ми використовуємо функцію print().

- Пишемо слово `print` обов'язково з маленької букви, python [[Регістрозалежність (Case Sensitivity)|регістрозалежна]] мова

``` python
my_name: str = "Дмитро"
print(my_name)
```

## Функція input()

Для того щоб ввести дані з клавіатури в програму використовується функція `input()`.  Незалежно від того, що саме вводить користувач, функція input() поверне об'єкт з типом даних `str`. 

Для того щоб працювати з даними які вводяться з клавіатури їх потрібно прив'язати до змінної. Нижче наведено приклад використання функції input().

``` python
my_name: str = input()
print(my_name)
```

## Перетворення типів (Type Conversion)

Тип даних об'єкта визначається в момент його створення в пам'яті. Однак в ході виконання програми може виникнути потреба змінити тип даних в об'єкта. Для цього використовуються спеціальні функції перетворення типів.

| **Функція**   | **Що робить (Опис)**                                                                | **Приклад (Код)**                 | **Результат**          |
| ------------- | ----------------------------------------------------------------------------------- | --------------------------------- | ---------------------- |
| **`int()`**   | Перетворює в **Ціле число**.<br><br>_(Відкидає дробову частину!)_                   | `int(3.9)`<br><br>`int("50")`     | `3`<br><br>`50`        |
| **`float()`** | Перетворює в **Дробове число**.<br><br>_(Додає .0, якщо його немає)_                | `float(10)`<br><br>`float("2.5")` | `10.0`<br><br>`2.5`    |
| **`str()`**   | Перетворює в **Текст (Рядок)**.<br><br>_(Працює майже з усім)_                      | `str(123)`<br><br>`str(9.5)`      | `"123"`<br><br>`"9.5"` |
| **`bool()`**  | Перетворює в **Логічне значення**.<br><br>_(Пусто/0 $\to$ False, решта $\to$ True)_ | `bool(1)`<br><br>`bool(0)`        | `True`<br><br>`False`  |
> [!danger] Назви функцій збігаються з назвою типу даних в які вони перетворюють. 

Приклад коду:

``` python
my_age: str = input()
my_age: int = int(my_age)
print(my_age)
```

1. Спочатку ми зчитуємо дані з клавіатури, за замовчуванням нам повернеться тип `str` тому ми вказуємо, що в даний момент змінна `my_age` зберігає об'єкт типу `string`
2. Ми розуміємо, що змінна має зберігати об'єкт у вигляді  числа і потрібно перетворити рядок на число.
3. Ми звертаємось до нашої змінної і вказуємо, що тепер вона буде зберігати число типу `integer`
4. Для того щоб перетворити отримані дані ми викликаємо функцію `int()` і передаємо в неї об'єкт за допомогою змінної 
5. Тепер змінна `my_age` посилається на число, що нам і потрібно
6. Функція `print()` тепер виведе саме число, а не текст

> [!attention] Важливо знати
> Функції перетворення типів не змінюють властивості об'єкта, а створюють на його основі новий з вказаним типом даних. 

Тому в результаті виконання наступного коду в пам'яті буде два об'єкти:

``` python
my_age: str = "10"
my_age2: int = int(my_age)
```

Оскільки ми створили нову змінну щоб перетворити тип даних `my_age2` то в змінній `my_age` так і буде зберігатись текст і до нього можна буде звертатись.

## Арифметичні операції

> [!term] Оператор (Operator) 
> Це символ, який каже комп'ютеру виконати певну математичну або логічну дію. Наприклад: `+`, `-`, `*`.

> [!term] Операнд (Operand) 
> Це дані (числа або змінні), над якими виконується дія. У виразі `5 + 2`: `5` і `2` — це операнди, а `+` — це оператор.

### Базові оператори

Тут все просто, але зверніть увагу на написання символів.

| **Операція**          | **Символ (Оператор)** | **Приклад** | **Результат** |
| --------------------- | --------------------- | ----------- | ------------- |
| **Додавання**         | `+`                   | `10 + 5`    | `15`          |
| **Віднімання**        | `-`                   | `10 - 5`    | `5`           |
| **Множення**          | `*`                   | `10 * 5`    | `50`          |
| **Ділення**           | `/`                   | `10 / 2`    | `5.0`         |
| Піднесення до степеня | `**`                  | `10 ** 2`   | `100`         |


> [!WARNING] Важливо про ділення /
> 
> Звичайне ділення в Python ЗАВЖДИ повертає дробове число (тип float), навіть якщо число ділиться націло.
> 
> - `10 / 2` $\to$ `5.0` (не `5`)
